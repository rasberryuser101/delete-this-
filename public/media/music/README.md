# Eigene Musik

Hier genau drei optionale MP3s hochladen: lobby.mp3 (Lobby), submit.mp3 (Fotoauswahl) und finale.mp3 (Endrangliste).
Bei Präsentation, Voting und Rundenergebnis läuft keine Hintergrundmusik und keine Ersatzmelodie. Soundeffekte bleiben aktiv.
Maximal 8 MB je Datei. Musik wird gestreamt und beim Wechsel der Phase vorbereitet; fehlt eine Datei, bleibt diese Phase stumm.
Anleitung im Repository: docs/ANPASSEN.md. Nur Audio mit passenden Nutzungs- und Veröffentlichungsrechten hochladen.
